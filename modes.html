Modes / ROBO SAHAYAK

Five ways to operate.

Idle/Initial is a state, not an operating mode.

RoboSahayak has five actual operating modes: Glove, Mobile Bluetooth Control, Human Following, Obstacle Avoidance and Voice Control.

01

Glove Mode

Purpose: Wearable locomotion and robotic-arm control.

Hardware/software: Arduino Nano, MPU6050, flex sensors, HC-05.

02

Mobile Bluetooth Control Mode

Purpose: App-based robot control through Bluetooth.

Hardware/software: RoboSahayak app, HC-05, Arduino UNO.

03

Human Following Mode

Purpose: Configured distance-based following behavior.

Hardware/software: HC-SR04, Arduino UNO and motors.

04

Obstacle Avoidance Mode

Purpose: Ultrasonic obstacle detection and avoidance.

Hardware/software: HC-SR04, Arduino UNO and motor drivers.

05

Voice Control Mode

Purpose: Voice-based commands through the mobile app.

Hardware/software: RoboSahayak app.
