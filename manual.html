01 / Introduction

Welcome to RoboSahayak.

Welcome to RoboSahayak, your intelligent helping robot.

RoboSahayak has been designed to assist elderly people, differently abled individuals, and anyone who needs help carrying or fetching everyday objects. It combines robotics, artificial intelligence, Bluetooth communication, and gesture control into one easy-to-use robotic assistant.

04 / Safety

Operate responsibly.

08 / Operating Modes

Five actual operating modes.

Idle/Initial state is not counted as an operating mode.

01 · Glove Mode

Use the gesture glove to control robot locomotion and robotic-arm functions.

02 · Mobile Bluetooth Control Mode

Move and operate the robot through the RoboSahayak mobile application over Bluetooth.

03 · Human Following Mode

The ultrasonic sensor provides distance information for the configured following behavior.

04 · Obstacle Avoidance Mode

Use the ultrasonic sensor to detect obstacles and support collision avoidance.

05 · Voice Control Mode

Use supported voice commands through the mobile application.

AI Assistant

The AI Assistant is an app feature for explanations, guidance and common questions; it is not counted as a sixth robot operating mode.

11 / Human Following

Configured distance logic.

0–39 cmRobot moves backward.
40–42 cmRobot stops.
43–100 cmRobot moves forward.

When activated, the ultrasonic sensor provides the distance measurement used by the configured following behavior. Ensure a clear sensing path.

17 / Troubleshooting

Quick fixes.

Robot not moving

  • Check battery.
  • Check Bluetooth connection.
  • Restart the robot.

Bluetooth not connecting

  • Ensure Bluetooth is enabled.
  • Stay within operating range.
  • Restart both robot and phone.

Robotic arm not responding

  • Check servo wiring.
  • Restart the robot.
  • Verify Bluetooth communication.

Human Following not working

  • Remove obstacles.
  • Ensure adequate sensing conditions.
  • Check the ultrasonic sensor.

20 / FAQ

Frequently asked questions.

Can RoboSahayak be controlled without the mobile app?

Yes. It can also be controlled using the gesture glove.

Does RoboSahayak work without Bluetooth?

Bluetooth is required for mobile app control. The glove controller also uses Bluetooth communication with the robot.

Can the robotic arm lift heavy objects?

No. Use only lightweight objects within the robot's design limits.

Is Human Following completely automatic?

Once activated, the robot follows the detected person according to its configured sensing behavior and distance logic.
