Features / ROBO SAHAYAK

Built to assist.

A focused set of project capabilities.

Every feature below comes directly from the RoboSahayak project specifications.

⌁

Glove Control

Arduino Nano, five flex sensors and MPU6050 provide wearable control.

⌘

Mobile Bluetooth Control

Control the robot through the RoboSahayak mobile application.

◎

Human Following

HC-SR04 distance measurements drive the configured following logic.

△

Obstacle Avoidance

The ultrasonic sensor supports obstacle detection and avoidance.

◉

Voice Control

Voice-based commands are supported through the mobile application.

⚙

Robotic Arm

Five SG90 servos, a stepper motor and gripper interact with objects.

05

Five Operating Modes

Glove, Mobile Bluetooth, Human Following, Obstacle Avoidance and Voice Control.

◴

Automatic Sleep

In Glove and Mobile Bluetooth modes, inactivity for 2 minutes triggers the specified sleep behavior.
